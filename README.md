# Way VPN Bot

Telegram-бот для персональных VPN: выбор срока и страны → оплата в RollyPay → оплаченная заявка → ручная выдача ссылки администратором.

## Оплата без вебхука

Бот создаёт ссылку RollyPay и проверяет результат через API. Ожидающие платежи проверяются примерно раз в минуту, ранее оплаченные и истёкшие — раз в час, чтобы обнаруживать возвраты и поздние оплаты. После простоя проверки продолжаются из базы. При большом числе заказов обход может занять больше времени.

Кнопка «Я оплатил — проверить» запускает немедленную проверку. Само нажатие не подтверждает оплату: тикет появляется только после статуса `paid` от RollyPay и проверки номера заказа, суммы, валюты и идентификатора платежа. Повторные ответы не создают повторной выдачи.

**Домен, почта, HTTPS и секрет вебхука не нужны.** Существующий вебхук другого бота не меняйте. Наша установка не занимает входящие порты сервера. Проверка кассы без вебхука на реальном аккаунте ещё требуется: локальные тесты используют имитацию RollyPay.

## Установка

Нужен Linux VPS с Docker Engine, Docker Compose v2 с `up --wait`, Git, Python 3 и flock. Установку Docker выполняйте по [официальной инструкции](https://docs.docker.com/engine/install/).

```sh
git clone https://github.com/asdasdasdasdasdaadas/way-vpn-bot.git
cd way-vpn-bot
./scripts/deploy.sh
```

Установщик запросит:
- `BOT_TOKEN` — токен от BotFather;
- `ADMIN_IDS` — числовые Telegram ID администраторов через запятую;
- `ROLLYPAY_API_KEY` — ключ кассы RollyPay;
- `ROLLYPAY_TEST` — сначала `true`, после проверки оплаты `false`.

Настройки сохраняются в `.env.production` с правами 600. Для запуска без вопросов заранее заполните файл по `.env.production.example`. Секреты в репозиторий не отправляйте. Перед запуском остановите другую копию с тем же токеном Telegram.

После запуска откройте `/start`, `/admin`, добавьте доступные страны. Проверьте тестовый платёж и ручную выдачу. Тестовая выдача не добавляет реальный срок подписки. Для реальных продаж установите `ROLLYPAY_TEST=false` и снова запустите скрипт. Демонстрационная имитация оплаты на сервере принудительно выключена.

## Возможности

- Главное меню в два ряда с цветными кнопками.
- Выбор страны; при продлении сохраняется прежняя страна.
- Управление ценами, сроками и локациями в Telegram.
- Заявки, ручная выдача ссылки, продление после подтверждения администратора.
- Личный кабинет со ссылкой, сроком и заказами.
- Текстовая поддержка, очередь уведомлений и напоминания об окончании.

Бот не создаёт VPN-серверы, не ограничивает устройства и не отключает доступ автоматически. Это делает администратор на VPN-сервере. Первая подписка начинается при выдаче ссылки; продление добавляется к оставшемуся сроку, а для истёкшей подписки — с момента выполнения.

## Тарифы

- 1 месяц — **1400 ₽**.
- 3 месяца — **4137 ₽**.
- 6 месяцев — **8148 ₽**.
- 12 месяцев — **15792 ₽**.

Расчёт: аренда 700 ₽ + наценка 700 ₽ за месяц, скидки 3/6/12% только на аренду. Комиссия 9% удерживается из цены, клиенту отдельно не начисляется. Тарифы меняются в админке; ранее созданные заказы сохраняют цены. Сроки календарные: учитывайте разницу, если провайдер продаёт аренду по 30 дней.

## Управление и обновление

```sh
./scripts/deploy.sh --update
./scripts/production.sh ps
./scripts/production.sh logs --tail=100 -f bot
./scripts/backup.sh
```

Обновление требует чистую ветку main, делает резервную копию работающей базы, выполняет fast-forward из GitHub и пересобирает контейнер. Перед запуском скрипт повторно проверяет настройки. При обновлении могут создаться две копии. Если существующий бот остановлен, сначала запустите его для резервного копирования.

Копии находятся в `backups/` и содержат личные VPN-ссылки. Переносите их в защищённое хранилище вне сервера. Не используйте `down -v`: это удалит данные. [Восстановление и обслуживание](deploy/DEPLOY.md).

## Админка

Каждый администратор сначала должен нажать `/start`. Команды: `/admin`, `/support`, `/paysupport`, `/cancel`, `/id`.

Для тарифа отправьте `Название | цена | месяцы`. В оплаченной заявке нажмите «Взять в работу», создайте VPN и выдайте ссылку. Для продления сначала продлите VPN на сервере, затем подтвердите выполнение в боте.

Если создание платежа завершилось тайм-аутом, заказ блокирует повторную покупку до сверки. Найдите платёж в RollyPay и выполните `/recover order_id payment_id`. Для восстановления неизвестного платежа требуется явный признак тестового режима в ответе API; если его нет, нужна помощь поддержки RollyPay. Если проверено, что платёж вообще не создан, используйте `/close_unpaid order_id` и подтвердите `НЕ СОЗДАН`.

Для платежей с уже сохранённым идентификатором режим определяется по заказу, если API не возвращает поле `test`. Возврат, обнаруженный при проверке API, блокирует невыполненную заявку и уведомляет администратора; уже выданный VPN нужно скорректировать вручную.

## Разработка

Python 3.9+ на Linux/macOS; Docker использует Python 3.12.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

Для локального запуска заполните `.env` по `.env.example`, укажите `DATABASE_PATH=data/bot.sqlite3`, `HOST=127.0.0.1` и запустите `.venv/bin/python run_local.py`.

Демо без кассы: `DEMO_MODE=true`, `ROLLYPAY_TEST=true`, отдельная база `data/demo.sqlite3`. Имитация оплаты доступна только администратору; тестовые подписки не меняют реальные. Германия, Нидерланды и Финляндия в демо — примеры, не подтверждённая инфраструктура.

Архив для сервера без секретов и баз: `python3 scripts/package.py`.

## Правила платформы

Telegram требует Stars для продажи цифровых услуг внутри ботов. Внешняя платёжка и отсутствие вебхука не отменяют это требование: [правила Telegram](https://core.telegram.org/bots/payments-stars). Выделенный IP не гарантирует отсутствие блокировок сторонних сервисов.
